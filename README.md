# Champion Coach v0.6.1

> **Repository edition:** v0.6.1 adds GitHub Actions validation, GitHub Pages deployment, `version.json`, and a cache revision so the repository can be the source of truth. App features are based on v0.6.0.


Pokémon Champions の復帰者・初心者向けに、**好きなポケモン1体から構築を始め、持っていないポケモンを避け、最初に試す育成案まで作る**ローカルWebアプリです。

## v0.6.1 の目的

v0.5.0 では「好きな1体 → 残り5体を仮組み」まで進められるようになりました。v0.6.0 では、その次に起こる2つの問題を解消します。

1. 提案されたポケモンを持っていない
2. 6体が決まっても、持ち物・性格・能力ポイント・技をどうすればよいか分からない

そのため、構築候補に「持っていない」を登録し、以後の仮組みから除外できるようにしました。また、保存した6体には初心者向けの「育成スターター」を表示します。

## 最初の流れ

1. 「構築」で好きなポケモンを1体選ぶ
2. その1体を軸に、残り5体を自分で選ぶか「おまかせで仮組み」
3. 候補を持っていなければ「持っていない」を押す
4. アプリが未所持を除外し、**役割の近さ + 今の構築の不足**から代替候補を表示
5. 6体を保存
6. 各ポケモンの育成スターターを確認
7. 相手6体を画像一覧から選び、対戦準備へ進む
8. 対戦後は勝敗・選出・事前プランの成否を記録する

## 未所持ポケモンと代替候補

### 「持っていない」

構築スロット・仲間候補・育成スターターから「未 / 持っていない」を押すと、そのポケモンを未所持として保存します。

- 以後のおまかせ仮組みから除外
- 通常の仲間候補から除外
- 保存済み構築に入っていれば、その構築からも外す
- 「持っていないポケモン」欄から「所持に戻す」ことが可能

相手として出てくる可能性はあるため、**相手6体の選択画面では未所持でも選べます。**

### 代替の考え方

「同じタイプだから」という理由だけでは置き換えません。次を合わせて評価します。

- 元のポケモンと近い役割（物理 / 特殊 / 高速 / 耐久 / 支援など）
- 現在の構築の共通弱点を減らせるか
- 物理・特殊・素早さ・耐久の不足を埋めるか
- ダブルでは支援・素早さ操作を補えるか
- 同タイプへの偏りを増やさないか
- 現行M-Cで採用例があるか（小さな補助点）

好きな軸を勝手に別ポケモンへ置き換えることはありません。軸そのものを未所持に登録した場合は、別の好きな1体を選び直すよう案内します。

## 育成スターター

構築を保存すると、6体それぞれについて次を表示します。

- おすすめ持ち物
- 持ち物の代替候補
- 性格
- **能力ポイント**
- 技候補（信頼できる現行データがある場合）
- 提案根拠の種類

### 能力ポイント

Pokémon Champions の表記に合わせ、従来作品の数値表記は使用しません。

- 1能力: 0～32
- 合計: 66

アプリの全スターター配分は、コード側で「各能力32以下・合計66」を検証しています。

性格と能力ポイントは、最初に対戦へ出しやすい**スターター案**です。個別の確定調整ではありません。高速アタッカー、耐久サポート、トリックルーム役など、現在判定できる役割に応じて配分を変えます。

例:

- 高速物理アタッカー: こうげき32 / すばやさ32 / HP2
- 高速特殊アタッカー: とくこう32 / すばやさ32 / HP2
- 耐久支援: HP32 + 低い方の耐久32 + 反対側2
- トリックルーム役: 役割の根拠がある場合のみ、素早さ下降性格を候補にする

**単に素早さ種族値が低いだけで「ゆうかん / れいせい」を強制しません。**

能力ポイントの公式表記例:
https://www.pokemon.com/us/features/pokemon-champions-how-to-build-a-mega-malamar-team

## 持ち物・技のデータ

### ダブル

Regulation M-C の公開対戦データを優先します。

- 使用率
- 技
- 持ち物

を取得し、アプリ内の日本語名へ変換します。オンライン取得に失敗しても使えるよう、2026-09-17時点の主要データを一部内蔵しています。

公開データ:
https://eurekaffeine.github.io/pokemon-champions-scraper/battle_meta.json

データ生成元:
https://github.com/eurekaffeine/pokemon-champions-scraper

技・持ち物の日本語名:
https://github.com/PokeAPI/pokeapi

Championsで新規追加されたメガストーン等は、公式日本語名を断定できない場合、「グソクムシャ用メガストーン」のような**説明用ラベル**で表示します。

### シングル

現在確認できる公開スクレイパーのSingles詳細は旧Regulationの統計を参照する場合があるため、v0.6.0ではそれを現行M-Cの根拠として流用しません。

そのためシングルでは、現行性を確認できない技構成を「おすすめ」と断定せず、

- 性格
- 能力ポイント
- 一般的なスターター持ち物

を先に表示します。技は現行M-Cの信頼できるデータを確認できた場合だけ拡張する設計です。

## 持ち物重複

同じ構築の6体へ同じ持ち物を重複提案しないよう、第一候補が他のポケモンと重なった場合は次候補へ切り替えます。

「持ち物重複を避けるため変更した」場合は育成カード内に表示します。

## 現行Regulation M-C

使用可能ポケモンの最終確認先は、ゲーム内のRoster Infoを推奨します。アプリのポケモンセレクターは現行Champions / Reg M-C実装を基準に258の通常・地域フォームを内蔵し、メガ進化可能なポケモンにはバッジを表示します。

公式Reg M-C告知:
https://www.pokemon.com/us/news/get-ready-for-regulation-set-m-c-in-pokemon-champions

## ポケモン選択

名前を知らなくても、カードから選べます。

- 画像（取得できる場合）
- 日本語名
- タイプ
- ざっくりした役割
- メガ進化可否
- 名前検索
- タイプ絞り込み

画像は本体へ同梱せず、PokéAPI spritesを読み込みます。取得できない場合は文字表示へ自動フォールバックし、選択・分析は継続できます。

## データ保存と通信

個人データはブラウザの `localStorage` に保存します。保存キーは旧版と同じ `championCoach.v1` です。

外部へ送信するのはありません。オンライン時に取得するのは、公開されているReg M-C環境データ・技名・持ち物名・ポケモン画像です。

設定画面からJSONバックアップを書き出し・読み込みできます。

### v0.5以前からの移行

- v0.5の構築・対戦ログを維持
- 旧 `メガボーマンダ` 等の構築名は通常種へ正規化
- 同種族別フォームが重複した不正データは1体へ整理
- 未所持に登録されたポケモンが保存構築へ同時に残る矛盾は読み込み時に解消


## GitHubリポジトリ運用

この版から、**GitHubリポジトリをソース・オブ・トゥルース**として運用できます。

- `main` = 公開可能な安定版
- 作業ブランチ = 改修中
- 作業ブランチ/PRでは `.github/workflows/validate.yml` が回帰検証
- `main` 更新時は `.github/workflows/pages.yml` が同じ検証を再実行
- 検証PASS後だけGitHub Pagesへデプロイ
- `version.json` / `latest.json` / Service Worker cache名で公開版を確認

初回だけGitHub側で空リポジトリを作成し、**Settings → Pages → Source → GitHub Actions** を選択します。以後はリポジトリ更新を中心に進められます。詳しい初期設定は `REPOSITORY_SETUP.md` を参照してください。

### リポジトリ構成

- `.github/workflows/validate.yml` — 作業ブランチ/PRの自動検証
- `.github/workflows/pages.yml` — mainの再検証とPages公開
- `version.json` — 人が確認するバージョン情報
- `latest.json` — build/cache/runtimeファイルSHA256
- `.nojekyll` — GitHub Pages用
- `.gitignore` — 一時ファイル除外

## 注意

- 「育成スターター」は、最初に対戦へ出すための土台です。すべての相手・構築に対する最適解を保証しません。
- 現行ダブルの技・持ち物は公開対戦データを根拠にしますが、性格・能力ポイントはアプリ側のスターター配分です。この2種類の根拠をUI上で分けて表示します。
- 少数使用のポケモンでは実戦データが不十分な場合があります。その場合は技を無理に断定しません。
- 環境は更新されるため、Roster Info・ゲーム内情報を最終確認先にしてください。
